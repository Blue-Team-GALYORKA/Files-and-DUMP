## Теория
Сервисы (службы, демоны) — программы, работающие в фоне, обычно запускаются при загрузке.
В большинстве дистрибутивов (Ubuntu, Debian, Kali, Fedora) управлением занимается `systemd`
через утилиту `systemctl`.

### Базовые команды systemctl
```bash
sudo systemctl start   имя     # запустить
sudo systemctl stop    имя     # остановить
sudo systemctl restart имя     # перезапустить
sudo systemctl status  имя     # статус
sudo systemctl enable  имя     # добавить в автозагрузку
sudo systemctl disable имя     # убрать из автозагрузки
systemctl list-units --type=service   # список всех сервисов
```

## 1. Apache (веб-сервер)
```bash
sudo apt-get install apache2
sudo systemctl start apache2
sudo systemctl enable apache2
sudo systemctl status apache2       # active (running)
```
Проверка: открыть в браузере `http://localhost` или `http://IP-сервера` — появится
страница «Apache2 Default Page». Проверка из консоли:
```bash
curl -I http://localhost            # HTTP/1.1 200 OK
```
Разместить свою страницу:
```bash
echo "<h1>Моя страница</h1>" | sudo tee /var/www/html/index.html
```
📷 СКРИНШОТ страницы Apache в браузере.

## 2. Telnet
> Telnet передаёт данные (включая пароли) открытым текстом — небезопасен, вытеснен SSH.
> Используем для учебной демонстрации.
```bash
sudo apt-get install telnetd telnet
sudo systemctl start inetd        # или openbsd-inetd, в зависимости от пакета
```
Проверка подключения к веб-серверу через telnet (ручной HTTP-запрос):
```bash
telnet localhost 80
```
После подключения ввести:
```
GET / HTTP/1.1
Host: localhost

```
(две клавиши Enter) — сервер вернёт HTTP-ответ. Выход: `Ctrl+]`, затем `quit`.
📷 СКРИНШОТ сессии telnet.

## 3. FTP (vsftpd)
```bash
sudo apt-get install vsftpd
sudo systemctl start vsftpd
sudo systemctl enable vsftpd
sudo systemctl status vsftpd
```
Базовая настройка в `/etc/vsftpd.conf`:
```
local_enable=YES       # разрешить вход локальным пользователям
write_enable=YES       # разрешить запись/загрузку
```
Перезапуск: `sudo systemctl restart vsftpd`. Подключение:
```bash
ftp localhost
# ввести логин и пароль пользователя, далее команды: ls, get, put, bye
```
📷 СКРИНШОТ сессии FTP.

## 4. SMB (Samba — общий доступ к файлам)
```bash
sudo apt-get install samba
sudo systemctl start smbd
sudo systemctl enable smbd
sudo systemctl status smbd
```
Посмотреть доступные сетевые ресурсы:
```bash
smbclient -L localhost -N
```
Подключиться к ресурсу:
```bash
smbclient //localhost/share -U kali
```
> Полная настройка общего ресурса Samba — в практической работе №4.1.
📷 СКРИНШОТ smbclient.

## Контрольные вопросы
- **Что такое сервис/демон?** — фоновая программа, часто запускаемая при загрузке системы.
- **Какая утилита управляет сервисами в systemd?** — `systemctl`.
- **Как добавить сервис в автозагрузку?** — `systemctl enable имя`.
- **Почему Telnet небезопасен?** — передаёт данные и пароли открытым текстом.
- **Как проверить, что Apache работает?** — `systemctl status apache2`, `curl -I http://localhost`, открыть в браузере.
- **Чем заменяют Telnet?** — SSH (шифрованный доступ).
