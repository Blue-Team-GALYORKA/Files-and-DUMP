## Теория: почему Vim устроен так
Vim — многорежимный редактор. В отличие от привычных Sublime/nano, в нём разделены
**ввод текста** и **редактирование/навигация**. «Горячие клавиши» нормального режима —
это не просто хоткеи, а система команд с аргументами (например, `d` + `w` = удалить
слово; число перед командой = повтор). Такой подход после привыкания ускоряет работу,
потому что руки не уходят с буквенного ряда.

## Режимы работы
| Режим | Как войти | Назначение |
|-------|-----------|------------|
| Нормальный | `Esc` | Навигация, команды редактирования (режим по умолчанию) |
| Вставки (Insert) | `i`, `a`, `I`, `A`, `o` | Набор текста |
| Визуальный | `v`, `V`, `Ctrl+v` | Выделение фрагментов |
| Командной строки | `:` | Сохранение, выход, поиск-замена |

Переходы в режим вставки:
- `i` — перед курсором, `a` — после курсора;
- `I` — в начало строки, `A` — в конец строки;
- `o` — новая строка ниже, `O` — новая строка выше.

Выделение:
- `v` — посимвольное, `V` — построчное, `Ctrl+v` — блочное (прямоугольник).

## Ход работы

### 1. Установка
```bash
sudo apt install vim        # Debian/Ubuntu/Kali
# sudo yum install vim      # CentOS
```

### 2. Создание файла и открытие
```bash
echo "Это новый файл. Вот вторая строчка, а это третья." >> newfile
vim newfile
```

### 3. Навигация (нормальный режим)
```
h — влево    j — вниз    k — вверх    l — вправо
gg — в начало документа
G  — в конец документа (5G — на 5-ю строку)
w  — к следующему слову      b — к предыдущему слову      e — к концу слова
0  — в начало строки         $ — в конец строки
```

### 4. Поиск текста
```
/это      → поиск вперёд по слову «это», Enter
/\cэто    → поиск без учёта регистра
/\Cэто    → поиск с учётом регистра
n         → следующее совпадение,  N → предыдущее
```

### 5. Редактирование
```
x   — удалить символ под курсором
dd  — удалить (вырезать) строку
dw  — удалить слово
yy  — скопировать строку (yank)
p   — вставить после курсора,  P — перед
u   — отменить (undo),  Ctrl+r — повторить (redo)
r   — заменить один символ
cw  — заменить слово
```

### 6. Сохранение и выход (командный режим, начинается с `:`)
```
:w    — сохранить
:q    — выйти
:wq   — сохранить и выйти (или ZZ в нормальном режиме)
:q!   — выйти без сохранения
:wq newfile2  — сохранить под другим именем
```

### 7. Поиск и замена
```
:%s/старое/новое/g     — заменить во всём файле (g — все вхождения в строке)
:%s/старое/новое/gc    — с подтверждением каждой замены
```

### 8. Интерактивное обучение
Пройти тренажёр https://www.openvim.com/ — он проводит по всем командам выше в браузере.

## Контрольные вопросы

**Что проделано в работе:** установлен Vim, создан и отредактирован файл, отработаны
навигация (`hjkl`, `gg`, `G`, `w`, `b`, `0`, `$`), переключение режимов, поиск (`/`, `n`,
`N`), редактирование (`x`, `dd`, `dw`, `yy`, `p`, `u`), поиск-замена (`:%s`), сохранение и
выход.

**Сколько режимов в Vim и зачем они нужны?** Основные — нормальный (навигация и команды),
вставки (набор текста), визуальный (выделение) и командный (`:` для сохранения/выхода).
Разделение режимов позволяет управлять редактором одними буквами без модификаторов.

**Как войти в режим ввода и выйти из него?** Войти — `i`/`a`/`I`/`A`/`o`; выйти в
нормальный режим — `Esc`.

**Как сохранить и выйти?** `:wq` или `ZZ`. Выйти без сохранения — `:q!`.

**Как удалить строку / слово / символ?** `dd` / `dw` / `x`.

**Как отменить действие?** `u` (undo), вернуть — `Ctrl+r`.

**Как сделать поиск без учёта регистра?** `/\cтекст`.

## Вывод
Освоены базовые принципы работы в Vim: многорежимная модель, навигация клавишами
`hjkl`, команды редактирования, поиск и замена, сохранение и выход. Понятно, почему
переключение режимов ускоряет работу опытного пользователя.
