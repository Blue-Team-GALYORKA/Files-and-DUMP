# Практическая работа №2.1. Основы мониторинга OS Linux

## Цель работы
Изучить работу утилит мониторинга: `df`, `du`, `free`, `iostat`, `mpstat`, `vmstat`, `w`, `htop`.

## Задача
- Изучить работу всех утилит.
- Работать исключительно в терминале.
- Включить в отчёт скриншоты всех указанных команд и опций.

## 1. df — свободное место на дисках
```bash
df            # в килобайтах
df -h         # человекочитаемо (M/G) — самый частый вариант
df -a         # все ФС, включая виртуальные
df -i         # информация об inode
df -t ext4    # только файловые системы типа ext4
df -x tmpfs   # все, кроме tmpfs
df -h /home   # по конкретному каталогу
```
Пример вывода `df -h`:
```
Filesystem      Size  Used Avail Use% Mounted on
/dev/vda        252G   13G   30G  30% /
tmpfs           7.9G   72K  7.9G   1% /dev/shm
```
Колонки: размер, занято, доступно, процент использования, точка монтирования.

## 2. du — размер файлов и каталогов
```bash
du -h ~/Documents          # размер каждого подкаталога
du -sh /var                # -s: только итог по каталогу
du -ah ~/Downloads         # -a: по каждому файлу
du -csh /var/log /var/lib  # -c: общий итог по нескольким
du -h --max-depth=1 /var   # глубина 1 уровень
```
Пример:
```
8.2M    /etc
```
5 самых больших подкаталогов:
```bash
sudo du -h /var/ | sort -rh | head -5
```

## 3. free — оперативная память
```bash
free          # в килобайтах
free -h       # человекочитаемо
free -m       # в мегабайтах,  free -g — в гигабайтах
free -s 2     # обновлять каждые 2 секунды
free -t       # строка итогов (total)
```
Пример `free -h`:
```
               total        used        free      shared  buff/cache   available
Mem:           7.8Gi       373Mi       7.5Gi        12Mi       164Mi       7.5Gi
Swap:             0B          0B          0B
```

## 4. vmstat — статистика виртуальной памяти, процессов, I/O
```bash
vmstat          # моментальный снимок
vmstat 2        # обновлять каждые 2 секунды
vmstat 2 5      # 5 замеров с интервалом 2 с
```
Пример:
```
procs -----------memory---------- ---swap-- -----io---- -system-- -------cpu-------
 r  b   swpd   free   buff  cache   si   so    bi    bo   in   cs us sy id wa st
 0  0      0 7868120   4500 169204    0    0   486   266  135    1  1  0 99  0  0
```
Колонки `r`/`b` — процессы в очереди/в ожидании; `us`/`sy`/`id` — загрузка CPU
(пользователь/система/простой).

## 5. iostat — загрузка CPU и дисков (пакет sysstat)
```bash
iostat          # сводка CPU + все устройства
iostat -x 2     # расширенная статистика, обновление 2 с
iostat -d       # только диски
```

## 6. mpstat — статистика по процессорам (пакет sysstat)
```bash
mpstat          # сводка по всем CPU
mpstat -P ALL   # отдельно по каждому ядру
mpstat 2 5      # 5 замеров с интервалом 2 с
```

## 7. w — кто в системе и чем занят
```bash
w
```
Пример:
```
 23:01:11 up 7 min,  0 user,  load average: 0.00, 0.00, 0.00
USER     TTY      FROM    LOGIN@   IDLE   JCPU   PCPU  WHAT
```
Показывает аптайм, load average и список активных пользователей.

## 8. htop — интерактивный монитор процессов
```bash
htop
```
Интерактивная таблица процессов с цветной шкалой CPU/RAM. Управление: `F6` — сортировка,
`F9` — послать сигнал (kill), `F4` — фильтр, `q` — выход.
📷 СКРИНШОТ интерфейса htop.

Изучены основные утилиты мониторинга Linux. `df`/`du` отвечают за дисковое пространство
