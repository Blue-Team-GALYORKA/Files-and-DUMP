# Практическая работа №2.5. Работа с .bashrc, .bash_profile и .bash_login

## Цель работы
Научиться работать с файлами `.bashrc`, `.bash_profile` и `.bash_login`.

## Задача
Разобраться, как эти файлы влияют на окружение оболочки bash.

> 📷 СКРИНШОТ: каждый шаг.

## Теория: когда какой файл читается

Bash при запуске читает разные файлы в зависимости от типа сессии:

| Файл | Когда выполняется |
|------|-------------------|
| `/etc/profile`, `/etc/bash.bashrc` | Общесистемные, для всех пользователей |
| `~/.bash_profile` | При **login-сессии** (вход в систему, SSH, вход в консоль) |
| `~/.bash_login` | При login-сессии, если нет `.bash_profile` |
| `~/.profile` | При login-сессии, если нет `.bash_profile` и `.bash_login` |
| `~/.bashrc` | При **интерактивной non-login** сессии (открытие нового окна терминала) |

Порядок для login-сессии: bash ищет `.bash_profile` → если нет, `.bash_login` → если нет,
`.profile`. Находит первый и больше остальные не читает. Поэтому часто в `.bash_profile`
дописывают вызов `.bashrc`, чтобы настройки применялись в обоих типах сессий:
```bash
if [ -f ~/.bashrc ]; then . ~/.bashrc; fi
```

## Ход работы

### 1. Посмотреть содержимое файлов
```bash
cat ~/.bashrc
cat ~/.bash_profile      # может отсутствовать
cat ~/.profile
```
Скрытые файлы (с точкой) видны через `ls -la ~`.

### 2. Добавить свой alias в .bashrc
```bash
nano ~/.bashrc
```
В конец файла добавить:
```bash
alias ll='ls -alF'
alias ..='cd ..'
alias gousr='cd /usr; ls; cd -'
```
Применить изменения без перезахода:
```bash
source ~/.bashrc      # или: . ~/.bashrc
```
Проверить:
```bash
ll
```
📷 СКРИНШОТ работающего alias.

### 3. Изменить приглашение командной строки (переменная PS1)
В `~/.bashrc` добавить:
```bash
export PS1='\u@\h:\w\$ '
```
- `\u` — пользователь, `\h` — хост, `\w` — текущий каталог.
Применить: `source ~/.bashrc`.

### 4. Добавить переменную окружения и путь
```bash
echo 'export MYVAR="Привет"' >> ~/.bashrc
echo 'export PATH=$PATH:$HOME/scripts' >> ~/.bashrc
source ~/.bashrc
echo $MYVAR          # проверка → Привет
echo $PATH           # в конце появится ~/scripts
```

### 5. Проверить разницу login / non-login
Создать метки в файлах:
```bash
echo 'echo "=== прочитан .bash_profile ==="' >> ~/.bash_profile
echo 'echo "=== прочитан .bashrc ==="' >> ~/.bashrc
```
- Новое окно терминала (non-login) → увидите только строку про `.bashrc`.
- Вход по SSH или `bash --login` → увидите строку про `.bash_profile`.
```bash
bash --login       # эмулировать login-сессию
```
📷 СКРИНШОТ обоих случаев.

### 6. Автозапуск команды при входе
В `~/.bash_profile` можно добавить приветствие или запуск скрипта:
```bash
echo 'echo "Добро пожаловать, $(whoami)! Сегодня $(date)"' >> ~/.bash_profile
```

## Контрольные вопросы
- **Когда читается .bashrc?** — при открытии интерактивного non-login терминала.
- **Когда читается .bash_profile?** — при login-сессии (вход в систему, SSH).
- **Что если нет .bash_profile?** — bash читает `.bash_login`, затем `.profile`.
- **Как применить изменения .bashrc без перезахода?** — `source ~/.bashrc`.
- **Где хранить постоянные alias?** — в `~/.bashrc`.
