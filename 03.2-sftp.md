# Практическая работа №3.2. Настройка SFTP и FileZilla

## Цель работы
Научиться настраивать SFTP (Secure File Transfer Protocol) и работать с FileZilla.

## Задача
- Установить и настроить SFTP.
- Научиться работать с SFTP.
- Научиться работать с FileZilla.

> 📷 СКРИНШОТ: каждый шаг.

---

## Теория
SFTP — протокол передачи файлов поверх защищённого канала SSH. Не путать с FTPS
(это FTP+TLS). SFTP не требует отдельного сервера: он работает через уже установленный
`sshd`. Весь трафик, включая логин и пароль, шифруется.

---

## Ход работы

### 1. Убедиться, что установлен SSH-сервер
```bash
sudo apt-get update
sudo apt-get install openssh-server
sudo systemctl status ssh      # active (running)
```
SFTP-подсистема включена в sshd по умолчанию. Проверить строку в конфиге:
```bash
grep -i sftp /etc/ssh/sshd_config
```
Ожидаемо:
```
Subsystem sftp /usr/lib/openssh/sftp-server
```

### 2. (Опционально) выделенный SFTP-доступ с chroot
Чтобы ограничить пользователя только его каталогом, в `/etc/ssh/sshd_config` добавить:
```
Match User sftpuser
    ChrootDirectory /home/sftpuser
    ForceCommand internal-sftp
    AllowTcpForwarding no
    X11Forwarding no
```
Создать пользователя:
```bash
sudo useradd -m sftpuser
sudo passwd sftpuser
sudo systemctl restart ssh
```

### 3. Подключение через консольный клиент sftp
```bash
sftp -P 2222 kali@192.168.1.50
```
Основные команды внутри сессии sftp:
```
pwd           # текущий каталог на сервере
lpwd          # текущий каталог локально (l = local)
ls            # список на сервере
lls           # список локально
put file.txt  # загрузить файл на сервер
get file.txt  # скачать файл с сервера
mkdir dir     # создать каталог на сервере
cd dir        # перейти в каталог на сервере
bye / exit    # выход
```
📷 СКРИНШОТ сессии sftp с командами put/get.

### 4. Работа через FileZilla (графический клиент на Windows)
1. Установить FileZilla Client (filezilla-project.org).
2. Меню **Файл → Менеджер сайтов → Новый сайт**.
3. Настройки:
   - **Протокол**: SFTP — SSH File Transfer Protocol;
   - **Хост**: `192.168.1.50`;
   - **Порт**: `2222`;
   - **Тип входа**: Запросить пароль (или «Обычный» с логином/паролем).
4. Нажать **Соединиться**, принять ключ хоста.
5. Слева — локальные файлы (Windows), справа — файлы на сервере. Перетаскиванием
   копировать файлы в обе стороны.
📷 СКРИНШОТ подключения FileZilla и передачи файла.

### 5. Проверка передачи
Загрузить тестовый файл через FileZilla, затем на сервере:
```bash
ls -l ~/uploaded_file.txt
```

## Контрольные вопросы
- **Чем SFTP отличается от FTP и FTPS?** — SFTP работает поверх SSH (отдельный протокол), FTPS — это FTP с TLS; SFTP шифрует всё, FTP передаёт данные открыто.
- **Нужен ли отдельный SFTP-сервер?** — нет, SFTP работает через sshd (Subsystem sftp).
- **Какой порт использует SFTP?** — тот же, что SSH (22 или заданный, здесь 2222).
- **Как загрузить/скачать файл в консоли sftp?** — `put` / `get`.
- **Как ограничить пользователя его каталогом?** — `ChrootDirectory` + `ForceCommand internal-sftp`.

## Вывод
Настроен доступ по SFTP через существующий SSH-сервер, отработана передача файлов
консольным клиентом (`put`/`get`) и графическим FileZilla. Рассмотрено ограничение
пользователя каталогом через chroot. SFTP обеспечивает шифрованную передачу файлов в
отличие от открытого FTP.
