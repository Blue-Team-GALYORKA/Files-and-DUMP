# Практическая работа №1.1. Работа в командной строке

## Цель работы
Научиться работать в командной строке Linux на уровне опытного пользователя.

## Задача
- Выполнить все задания.
- Работать исключительно в терминале.

> Работа выполнялась в дистрибутиве Debian/Ubuntu (Kali) под пользователем с правами sudo.
> 📷 СКРИНШОТ: делайте скриншот терминала после каждого блока команд.

---

## Ход работы

### 1. Под каким пользователем работаем в системе
```bash
whoami
```
Команда выводит имя текущего пользователя. Пример вывода:
```
kali
```

### 2. Перейти в корневой каталог
```bash
cd /
```
`/` — корень файловой системы. После перехода приглашение показывает `/`.

### 3. Посмотреть содержимое каталога
```bash
ls
```
Выводит список файлов и папок текущего каталога. Для подробного вида — `ls -l`.

### 4. Определить тип команд ls и cd
```bash
type ls
type cd
```
Вывод:
```
ls is /usr/bin/ls          # ls — внешняя программа (исполняемый файл на диске)
cd is a shell builtin      # cd — встроенная команда оболочки bash
```
`cd` встроена в оболочку, потому что должна менять каталог самого процесса bash; будь она отдельной программой, она меняла бы каталог только в дочернем процессе.

### 5. Из корневого каталога посмотреть содержимое /home
```bash
cd /
ls home
```
Выводит список домашних каталогов пользователей (например, `kali`).

### 6. Перейти в /tmp
```bash
cd /tmp
```

### 7. Создать директорию /pt
```bash
sudo mkdir /pt
```
`mkdir` создаёт каталог. Для записи в корень `/` нужны права root, поэтому `sudo`.
(Если по смыслу задания каталог нужен внутри /tmp — `mkdir /tmp/pt`.)

### 8. Создать 3 текстовых документа
```bash
cd /pt
sudo touch 1.txt 2.txt 3.txt
ls -l
```
Вывод:
```
-rw-r--r-- 1 root root 0 ноя 19 22:58 1.txt
-rw-r--r-- 1 root root 0 ноя 19 22:58 2.txt
-rw-r--r-- 1 root root 0 ноя 19 22:58 3.txt
```
`touch` создаёт пустые файлы (или обновляет время доступа у существующих).

### 9. Изменить/добавить содержимое через nano и vim
```bash
nano 1.txt
```
Ввести текст → сохранить `Ctrl+O`, Enter → выйти `Ctrl+X`.
```bash
vim 2.txt
```
Нажать `i` (режим ввода) → ввести текст → `Esc` → `:wq` (сохранить и выйти).
📷 СКРИНШОТ редакторов nano и vim с введённым текстом.

### 10. Скопировать и переименовать директорию с файлами
```bash
cd /tmp
sudo cp -r /pt /pt_copy        # копируем каталог рекурсивно
sudo mv /pt_copy /pt_backup    # переименовываем (mv = move/rename)
ls -ld /pt_backup
```
`cp -r` — рекурсивное копирование каталога, `mv` — перемещение/переименование.

### 11. Заархивировать директорию
```bash
cd /
sudo tar -czvf pt.tar.gz pt
```
- `c` — создать архив, `z` — сжать gzip, `v` — показать файлы, `f` — имя файла.

### 12. Разархивировать директорию
```bash
sudo tar -xzvf pt.tar.gz -C /tmp
```
`x` — извлечь, `-C /tmp` — распаковать в каталог /tmp.

### 13. Посмотреть содержимое домашней директории и /usr одной командой
```bash
ls ~ /usr
```
`ls` принимает несколько путей сразу и выводит содержимое каждого.

### 14. Посмотреть содержимое каталога в обратном порядке
```bash
ls -r
```
Вывод (пример):
```
3.txt
2.txt
1.txt
```
`-r` — reverse, обратный порядок сортировки.

### 15–16. Посмотреть права на директорию и на текстовые файлы
```bash
ls -ld /pt        # права на саму директорию
ls -l /pt/*.txt   # права на файлы внутри
```
Пример строки прав: `drwxr-xr-x` — каталог (d), владелец rwx, группа r-x, остальные r-x.

### 17. Переместить и переименовать один файл в /tmp
```bash
sudo mv /pt/1.txt /tmp/one.txt
```

### 18. Новая директория + файл + перемещение с заменой и запросом
```bash
mkdir ~/newdir
touch ~/newdir/new.txt
sudo mv -i /tmp/one.txt ~/newdir/new.txt
```
`mv -i` (interactive) спросит подтверждение перед заменой существующего файла:
```
mv: overwrite '/root/newdir/new.txt'? y
```

### 19. Определить местоположение исполняемого файла ls и cd
```bash
which ls      # /usr/bin/ls
which cd      # ничего не выведет — cd встроена в оболочку
type cd       # cd is a shell builtin
```

### 20. Краткое описание команд ls, nano, rm
```bash
whatis ls
whatis nano
whatis rm
```
Если `whatis` не настроен (`nothing appropriate`), обновите базу: `sudo mandb`, либо
используйте `ls --help | head`, `man ls`.

### 21. Создать символические ссылки
```bash
cd ~
echo "hello" > file.txt
ln -s file.txt file_link
ls -l file_link
```
Вывод:
```
lrwxrwxrwx 1 kali kali 8 ноя 19 22:58 file_link -> file.txt
```
`ln -s` — символическая (мягкая) ссылка: указывает на путь к файлу.

### 22. Символическая ссылка «в никуда» (битая)
```bash
ln -s /nope/missing dead_link
ls -l dead_link
```
Вывод:
```
lrwxrwxrwx 1 kali kali 13 ноя 19 22:58 dead_link -> /nope/missing
```
Цель не существует — в графических файловых менеджерах такая ссылка подсвечивается
красным, при открытии: `No such file or directory`.

### 23. Создать прямые (жёсткие) ссылки
```bash
ln file.txt file_hard
ls -li file.txt file_hard
```
Вывод:
```
1138722 -rw-r--r-- 2 kali kali 6 ноя 19 22:58 file.txt
1138722 -rw-r--r-- 2 kali kali 6 ноя 19 22:58 file_hard
```
Одинаковый номер inode (1138722) и счётчик ссылок `2` — оба имени указывают на одни
и те же данные на диске. В отличие от символической, жёсткая ссылка остаётся рабочей
даже после удаления исходного имени.

### 24. Создать собственную команду через alias
```bash
alias gousr='cd /usr; ls; cd -'
gousr
```
`alias` задаёт псевдоним. `cd -` возвращает в предыдущий каталог. Чтобы алиас
сохранялся после перезапуска — добавить строку в `~/.bashrc`.

### 25. Через cat написать текст и записать в файл
```bash
cat > mytext.txt
Любой текст тут
(нажать Ctrl+D для завершения ввода)
cat mytext.txt
```
`cat > file` читает ввод с клавиатуры и пишет в файл до `Ctrl+D`.

### 26. Удалить один текстовый файл
```bash
rm mytext.txt
```

### 27. Создать пустую директорию и удалить её
```bash
mkdir empty_dir
rmdir empty_dir
```
`rmdir` удаляет только пустой каталог.

### 28. Удалить директорию с 3 файлами
```bash
rm -r /pt
```
`rm -r` удаляет каталог со всем содержимым рекурсивно.

### 29. Создать пользователя
```bash
sudo useradd -m student
```
`-m` создаёт домашний каталог `/home/student`.

### 30. Поменять пароль нового пользователя
```bash
sudo passwd student
```
Дважды ввести новый пароль (на экране не отображается).

### 31. Найти текстовый документ через find и grep
```bash
touch ~/target.txt
find ~ -name "*.txt" | grep target
```
Вывод:
```
/root/target.txt
```
`find` ищет файлы по имени, `grep` фильтрует строки вывода по шаблону.

### 32. Логические «И» и «ИЛИ» на примере ping
```bash
ping -c1 8.8.8.8 && echo "Сеть доступна"     # && — выполнить второе, если первое успешно (И)
ping -c1 10.0.0.255 || echo "Хост недоступен" # || — выполнить второе, если первое неуспешно (ИЛИ)
```
`&&` запускает правую команду только при коде возврата 0 (успех), `||` — только при ненулевом коде (ошибка).

В ходе работы отработаны базовые операции в терминале Linux: навигация по файловой
системе, создание/копирование/перемещение/удаление файлов и каталогов, архивация
(`tar`), работа с правами (`ls -l`), символические и жёсткие ссылки (`ln`), создание
пользователей (`useradd`, `passwd`), поиск (`find`, `grep`), псевдонимы (`alias`) и
логические операторы `&&` / `||`. Освоены различия между встроенными командами оболочки
и внешними программами (`type`, `which`).
