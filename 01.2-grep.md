## Ход работы

### 1.1. Поиск установленной версии Python
Вопрос задания: как узнать, какие версии Python установлены в системе?
```bash
dpkg -l | grep -i python
```
- `dpkg -l` выводит список всех установленных .deb-пакетов.
- `| grep -i python` оставляет только строки со словом python; `-i` игнорирует регистр.

Пример вывода:
```
ii  python2.7            Interactive high-level object-oriented language (version 2.7)
ii  python-openssl       Python wrapper around the OpenSSL library
```
Первый столбец `ii` — пакет установлен корректно.

### 1.2. Удалить все закомментированные строки из конфига
Вопрос: как показать конфиг Apache без комментариев?
```bash
grep -v "#" /etc/apache2/sites-available/default-ssl.conf
```
`-v` (invert) инвертирует результат: выводятся строки, которые **не** содержат `#`,
то есть незакомментированные. (Строгий вариант «только строки, начинающиеся с #»:
`grep -v "^#"`.)

### 1.3. Найти все .mp3 исполнителя ABC без ремиксов
```bash
find . -name "*.mp3" | grep -i ABC | grep -vi "remix"
```
Проверено на тестовых файлах:
```
./music/ABC - song.mp3
```
(файл `ABC - song (remix).mp3` отфильтрован вторым grep). Цепочка:
`find` выводит все mp3 → `grep -i ABC` оставляет файлы с ABC → `grep -vi remix`
убирает ремиксы.

### 1.4. Количество строк до/после совпадения
```bash
ifconfig | grep -A 4 eth0     # A = After: совпадение + 4 строки после
ifconfig | grep -B 2 UP       # B = Before: совпадение + 2 строки до
```

### 1.5. Строки в обе стороны от совпадения
```bash
ifconfig | grep -C 2 lo       # C = Context: по 2 строки до и после
```

### 1.6. Подсчитать количество совпадений
```bash
ifconfig | grep -c inet6
```
`-c` (count) выводит число совпавших строк, пример вывода: `2`.

### 1.7. Поиск с номерами строк
```bash
grep -n "main" setup.py
```
`-n` добавляет номер строки. Пример:
```
2:def main():
4:main()
```

### 1.8. Рекурсивный поиск по всем подкаталогам
```bash
grep -r "function" *
```
`-r` (recursive) ищет во всех файлах текущего каталога и вложенных.

### 1.9. Поиск по целому слову
```bash
ifconfig | grep -w "RUNNING"   # найдёт слово RUNNING
ifconfig | grep -w "RUN"       # ничего не выведет — RUN не целое слово
```
`-w` требует совпадения целого слова, а не подстроки.

### 1.10. Поиск в архивах gzip
```bash
zgrep -i error /var/log/syslog.2.gz
```
`zgrep` работает как `grep`, но прозрачно читает сжатые gzip-файлы. Проверено:
```
error: disk full
```

### 1.11. Создание zip-архива (для п.1.10)
```bash
zip myfile.zip myfile.txt                    # один файл
zip myarchive.zip f1.txt f2.txt f3.txt       # несколько файлов
zip -r mydir.zip verygooddir                 # папка рекурсивно (-r)
zip -er mysecret.zip mysecretdir             # с паролем (-e скрытый ввод)
unzip myfile.zip                             # распаковать в текущий каталог
unzip myfile.zip -d mydir                    # распаковать в каталог mydir
```

## Ответы на вопросы задания
- **Две версии Python, какая установлена** → `dpkg -l | grep -i python`.
- **Убрать комментарии из конфига** → `grep -v "^#" файл`.
- **Найти .mp3 ABC без ремиксов** → `find . -name "*.mp3" | grep -i ABC | grep -vi remix`.
- **Строки до/после совпадения** → `-A N` (после), `-B N` (до).
- **Количество строк совпадения** → `-c`.
- **Количество совпадений** → тоже `-c` (считает строки с совпадением).
- **Поиск по номерам строк** → `-n`.
- **Рекурсивный поиск** → `grep -r "строка" *`.
- **Поиск в gzip-архивах** → `zgrep`.

## Вывод
Изучены основные опции `grep`: `-i` (регистр), `-v` (инверсия), `-c` (счётчик),
`-n` (номера строк), `-r` (рекурсия), `-w` (целое слово), `-A/-B/-C` (контекст), а также
`zgrep` для сжатых файлов. `grep` особенно эффективен в связке с `find` и конвейером `|`.
