# Практическая работа №2.2. Установка и настройка сервера SSH

## Цель работы
Научиться настраивать SSH-сервер и клиент.

## Задача
- Установить, настроить SSH-сервер и клиент.
- Отключить доступ по пользователю root.
- Сменить порт по умолчанию на любой другой.
- Подключиться к серверу Linux с хостовой ОС через PuTTY.
- Составить отчёт в виде инструкции со скриншотами.

> 📷 СКРИНШОТ: каждый шаг сопровождайте скриншотом терминала/PuTTY.

---

## Теория
SSH (Secure Shell) — протокол защищённого удалённого управления с шифрованием трафика.
В Linux используется реализация OpenSSH: демон `sshd` (сервер) и утилиты `ssh`, `scp`,
`ssh-keygen`. Конфигурация сервера — `/etc/ssh/sshd_config`.

## Ход работы

### 1. Установка пакетов SSH
```bash
# Ubuntu/Debian/Kali
sudo apt-get update
sudo apt-get install ssh

# CentOS
# sudo yum -y install openssh-server openssh-clients
```

### 2. Проверка статуса сервера
```bash
sudo systemctl status ssh
```
Должно быть `active (running)`. Если не запущен:
```bash
sudo systemctl start ssh
sudo systemctl enable ssh      # автозапуск при загрузке
```
📷 СКРИНШОТ статуса `active (running)`.

### 3. Открыть конфигурацию сервера
```bash
sudo nano /etc/ssh/sshd_config
```

### 4. Сменить порт по умолчанию (22 → например 2222)
Найти строку `#Port 22`, раскомментировать (убрать `#`) и изменить:
```
Port 2222
```
> Нестандартный порт снижает количество автоматических сканирований и брутфорса ботами.

### 5. Отключить доступ по root
Найти `PermitRootLogin` и задать:
```
PermitRootLogin no
```

### 6. (Рекомендуется) ограничить версию протокола и пользователей
```
Protocol 2
AllowUsers kali
```

### 7. Применить настройки — перезапустить сервер
```bash
sudo systemctl restart ssh
```
Проверить, что сервис слушает новый порт:
```bash
sudo ss -tlnp | grep ssh
```
Ожидаемо: `LISTEN ... :2222`.
📷 СКРИНШОТ вывода `ss` с портом 2222.

### 8. Открыть порт в брандмауэре (если включён ufw)
```bash
sudo ufw allow 2222/tcp
```

### 9. Подключение из Windows через PuTTY
1. Узнать IP сервера Linux:
   ```bash
   ip a    # смотрим адрес, например 192.168.1.50
   ```
2. Запустить **PuTTY** на Windows.
3. В поле **Host Name (or IP address)** — `192.168.1.50`.
4. В поле **Port** — `2222`.
5. **Connection type**: SSH → нажать **Open**.
6. При первом подключении — принять ключ хоста (Accept).
7. Ввести логин (не root!) и пароль.
📷 СКРИНШОТ окна PuTTY с настройками и успешного входа.

### 10. Проверка отключения root
Попытка войти под root должна быть отклонена:
```
login as: root
root@192.168.1.50's password:
Access denied
```
📷 СКРИНШОТ отказа для root.

## Контрольные вопросы
- **Где хранится конфигурация sshd?** — `/etc/ssh/sshd_config`.
- **Как сменить порт?** — параметр `Port` в конфиге + перезапуск `sshd`.
- **Как запретить вход root?** — `PermitRootLogin no`.
- **Чем SSH лучше Telnet?** — SSH шифрует весь трафик, включая пароли; Telnet передаёт данные открытым текстом.
- **Как применить изменения конфига?** — `sudo systemctl restart ssh`.
