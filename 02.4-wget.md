## 1. Базовый сбор информации о системе

### Дистрибутив и версия
```bash
cat /etc/os-release        # современный способ
cat /etc/*release          # универсально
lsb_release -a             # если установлен lsb-release
```

### Информация о ядре
```bash
uname -a
```
Пример:
```
Linux vm 6.18.44 #1 SMP PREEMPT_DYNAMIC x86_64 GNU/Linux
```
Показывает имя ядра, хост, версию, архитектуру.

### Текущий пользователь и время работы системы
```bash
whoami        # имя текущего пользователя
uptime        # как долго работает система + load average
```
> Если система работает без перезагрузок очень долго, значит не ставились обновления
> ядра — потенциальные непропатченные уязвимости.

### Права на домашние каталоги
```bash
ls -ld /home/*
```
Ограничить доступ других пользователей к своему каталогу:
```bash
sudo chmod o-rx /home/kali
```
`o-rx` снимает права чтения и входа для «остальных» (other) — чужие пользователи больше
не смогут зайти в каталог.

### Сетевая активность и сервисы
```bash
ip neigh          # ARP-таблица: с какими хостами идёт обмен
sudo ss -tlnp     # какие сервисы слушают какие TCP-порты
sudo -l           # какие команды текущий пользователь может запускать через sudo
```

## 2. SUID-файлы
SUID (setuid) — бит прав, позволяющий запускать файл с правами его владельца (часто
root). Такие файлы — потенциальный вектор повышения привилегий.
Найти все SUID-файлы владельца root:
```bash
sudo find / -user root -perm -4000 -exec ls -ldb {} \; 2>/dev/null
```
- `-perm -4000` — установлен бит SUID; `2>/dev/null` — скрыть ошибки доступа.

## 3. Скачивание файлов через wget и проверка целостности

### Установка wget (если нет)
```bash
sudo apt-get install wget
```

### Скачать утилиту аудита Lynis в /tmp
```bash
cd /tmp
wget https://downloads.cisofy.com/lynis/lynis-3.0.6.tar.gz
```

### Распаковать архив
```bash
tar xfv lynis-3.0.6.tar.gz
```
Опции tar: `x` — извлечь, `f` — имя файла, `v` — подробный вывод.

### Проверить контрольную сумму (целостность)
```bash
sha256sum lynis-3.0.6.tar.gz
```
Сравнить полученную строку с суммой, опубликованной на сайте. Если совпадает — файл не
повреждён и не подменён. Пример эталонной суммы из задания:
```
3005346e90339c18a4c626169c6f1d9fb8643bb0d0a049bcaf64b7ccb4fd272c
```

### Запустить аудит системы Lynis
```bash
cd lynis
sudo ./lynis audit system
```
Утилита проверит конфигурацию безопасности и выдаст отчёт с предупреждениями (warnings)
и рекомендациями (suggestions).

## Контрольные вопросы
- **Как узнать дистрибутив и версию ядра?** — `cat /etc/os-release`, `uname -a`.
- **Что показывает uptime и чем это важно для ИБ?** — время работы без перезагрузки; долгий аптайм = давно не обновлялось ядро.
- **Что такое SUID и чем опасен?** — бит запуска с правами владельца; SUID-файлы root могут использоваться для повышения привилегий.
- **Зачем проверять контрольную сумму?** — убедиться, что скачанный файл не повреждён и не подменён.
- **Какой командой считается SHA-256?** — `sha256sum файл`.
