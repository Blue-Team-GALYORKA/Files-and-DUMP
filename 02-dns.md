# Практическая работа №2 (Web). Архитектура WEB: DNS

## Цель работы
- Познакомиться с архитектурой WEB.
- Познакомиться с протоколом DNS и его работой.

## Задание
1. Выполнить запрос к корневым DNS-серверам и посмотреть их список.
2. Выяснить, какие серверы отвечают за зону `ru`.
3. Выяснить, сколько почтовых серверов у `ptsecurity.com`.
4. Выяснить, какое имя связано с IP-адресом `77.88.8.7`.

> Запросы выполняются в Windows (`nslookup`) и/или в Linux (`dig`/`host`).
> 📷 СКРИНШОТ: вывод каждой команды.

---

## Теория
DNS (Domain Name System) переводит доменные имена в IP-адреса. Иерархия: корневые
серверы (`.`) → серверы доменов верхнего уровня (`ru`, `com`) → авторитетные серверы зоны.
Типы записей: `A` (IPv4), `AAAA` (IPv6), `NS` (серверы имён), `MX` (почтовые серверы),
`PTR` (обратное разрешение IP → имя), `CNAME` (псевдоним).

---

## Ход работы

### 1. Корневые DNS-серверы
**Windows (nslookup):**
```cmd
nslookup -q=ns .
```
или в интерактивном режиме:
```
nslookup
> set type=ns
> .
```
**Linux (dig):**
```bash
dig NS . +short
```
Вывод — список 13 корневых серверов `a.root-servers.net` … `m.root-servers.net`.
📷 СКРИНШОТ списка корневых серверов.

### 2. Серверы зоны ru
**Windows:**
```cmd
nslookup -q=ns ru.
```
**Linux:**
```bash
dig NS ru. +short
```
Вывод — авторитетные NS-серверы зоны `ru` (например `a.dns.ripn.net`, `b.dns.ripn.net` и др.).
📷 СКРИНШОТ.

### 3. Почтовые серверы ptsecurity.com (MX-записи)
**Windows:**
```cmd
nslookup -q=mx ptsecurity.com
```
**Linux:**
```bash
dig MX ptsecurity.com +short
```
В выводе — список MX-записей с приоритетами (меньшее число = выше приоритет). Количество
строк MX = число почтовых серверов.
📷 СКРИНШОТ MX-записей.

### 4. Обратное разрешение IP 77.88.8.7 (PTR)
**Windows:**
```cmd
nslookup -q=ptr 77.88.8.7
```
**Linux:**
```bash
dig -x 77.88.8.7 +short
host 77.88.8.7
```
Вывод покажет имя, связанное с адресом (это один из DNS-серверов Яндекса — `dns.yandex.ru`
семейства 77.88.8.x).
📷 СКРИНШОТ PTR-записи.

### Дополнительно: прочие полезные запросы
```bash
dig A example.com +short          # IPv4-адрес домена
dig AAAA example.com +short       # IPv6-адрес
dig example.com ANY               # все записи
dig @8.8.8.8 example.com          # запрос к конкретному DNS-серверу (Google)
```

## Контрольные вопросы
- **Что такое DNS?** — система перевода доменных имён в IP-адреса.
- **Сколько корневых DNS-серверов?** — 13 логических (a–m root-servers).
- **Какая запись отвечает за почтовые серверы?** — `MX`.
- **Что делает PTR-запрос?** — обратное разрешение: по IP находит доменное имя.
- **Как узнать NS-серверы зоны?** — `nslookup -q=ns зона` / `dig NS зона`.
- **Как задать тип запроса в nslookup?** — `set type=` или ключ `-q=`.

Изучена работа протокола DNS и его иерархия. С помощью `nslookup` (Windows) и `dig`/`host`

MX-записи `ptsecurity.com` и обратное разрешение (PTR) IP-адреса `77.88.8.7`.
